# 실사감 검토 (2026-11-09 05:17 KST 기준)

현재 결과물은 "잘 만든 게임 캐릭터" 수준이고, 사진으로 착각할 수준은 아니다.
렌더러 쪽(SSS, 굴절 안구, PCSS 그림자, HDRI 조명, 피사계심도)은 갖춰졌지만,
실사감을 결정하는 **데이터**가 부족한 것이 핵심 원인이다.

## 실사와 멀어 보이는 원인 (영향 큰 순)

1. **머리카락 없음** — 민머리 + 텍스처로 그린 버즈컷. 사람이 CG 마네킹으로 인식하는 가장 강한 단서.
   제대로 하려면 수만 가닥 스트랜드(또는 헤어 카드) + 머리카락 전용 셰이딩(Marschner) + 자기 그림자가 필요.
2. **피부 텍스처가 절차적(노이즈 기반)** — 실제 디지털 휴먼은 4–8K 스캔 알베도와 디스플레이스먼트
   (모공, 잔주름, 잡티, 비대칭 색 얼룩)를 쓴다. 노이즈로 만든 색/요철은 지나치게 깨끗하고 균일해 보인다.
3. **형상 디테일 부족** — ICT-FaceKit Light 메시(얼굴 약 9천 정점)는 매끈한 평균형 표면이고 변위맵이 없다.
4. **평균 얼굴 효과** — PCA 정체성 모드는 대칭적이고 개성이 약해 "합성된 평균 얼굴"처럼 보인다.
5. **입술·눈 주변 디테일** — 입술 주름/수분감, 눈물 메니스커스, 눈 안쪽 누구(caruncle), 홍채 깊이감이 단순하다.
6. **조명** — 절차적 스튜디오 조명은 인공적이었다. 실제 촬영 HDRI(창가/야외)로 바꾼 뒤 확연히 나아졌다(현재 기본값).
7. **검증 스크린샷의 한계** — 컨테이너에 GPU가 없어 소프트웨어 GL로 1배율 렌더했다. 실제 GPU 브라우저에서는
   더 선명하지만, 위 1–5의 근본 원인은 바뀌지 않는다.

## 확인된 사항

- SSS는 동작한다. 다만 켜고 끈 차이가 눈가·콧구멍·입술 선에만 나타나 플라스틱 느낌의 주원인은 아니었다.
- PCSS 그림자, 표정(웃음 시 치아/눈 찡그림/눈썹 추종), 3D 눈썹 털, HDRI 조명은 정상 동작.

## 진짜 실사로 가는 선택지 (다음 세션에서 결정 필요)

| 선택지 | 결과 | 비용/제약 |
| --- | --- | --- |
| A. 고해상도 헤드 스캔 데이터 사용 (구매 스캔 또는 사진측량 촬영) | 현재 실시간 렌더러로 즉시 큰 향상. 실사에 가장 가까움 | 라이선스/비용, 공개 저장소 재배포 제한, 실존 인물 얼굴이 됨 |
| B. 오프라인 패스트레이싱 (Blender Cycles) | 정지 이미지는 사진급 가능 (머리카락 포함) | 실시간 아님, 프레임당 수 분 |
| C. 생성형 이미지 모델 (2D) | 즉시 사진급 2D 얼굴 | 3D/표정 제어 제한 |
| D. 현재 절차적 방식 계속 고도화 (스트랜드 헤어, 예제 기반 피부 텍스처 합성, 비대칭) | 점진적 향상 | 상한선은 고급 게임 캐릭터 수준 |

권장: 실시간 3D가 목표면 **A**(스캔 텍스처 + 현 렌더러), 정지 이미지면 **B**.

## 다음에 바로 할 수 있는 작업 (선택지 D 기준)

- 짧은 머리 스트랜드 헤어 (눈썹 털 시스템을 두피로 확장, 수만 가닥 인스턴싱)
- 피부 알베도: 실제 피부 사진(CC0) 기반 예제 텍스처 합성으로 노이즈 대체
- 얼굴 비대칭/잡티/모공 분포의 영역별 변화
- 입술 세로 주름 강화, 눈물 메니스커스·누구 추가
